## II. Security and Agent Boundaries

### 4. Researchers disclose two OpenAI Codex sandbox escapes; OpenAI patched them in eight days (Security)
**Summary:** BleepingComputer reported on September 20 that Oren Yomtov of Accomplish AI disclosed two Codex sandbox flaws to OpenAI on August 12. The more serious issue, Heapjack, could run unsandboxed host commands from Codex's most locked-down mode with no approval prompt. Overpatch abused the CLI apply_patch tool in workspace-write mode to write outside the project tree. OpenAI fixed Heapjack in Codex Desktop build 26.818.21641 and Overpatch in Codex CLI 0.149.0, about eight days after the report. Users are advised to update to those versions or later.

**Links:**

- [BleepingComputer — Researchers escape OpenAI Codex sandbox to run commands on host](https://www.bleepingcomputer.com/news/security/researchers-escape-openai-codex-sandbox-to-run-commands-on-host/)

**Commentary:** Alignment talk does not replace process isolation—one sandbox miss turns a coding agent into a production host.

## IV. Products and Models

### 7. TypeSafe ships Jev, a decision model that skips chat for millisecond structured judgments (Product)
**Summary:** TechSpot on September 20 covered TypeSafe AI's first System One model, Jev, from Diogo Almeida, who worked on OpenAI RLHF research. Jev does not write email or hold conversations; it takes application state plus typed Choice, Score, or Noul questions and returns choices, scores, and confidence values. TypeSafe cites roughly 70–500 ms latency and pricing of about $0.042 per million input tokens with free output. Internal workflow tests showed about 67.8% agreement with averaged GPT-6 Astra and Fable 5.1 answers, with claimed extreme speed and cost advantages; the product is in early access.

**Links:**
