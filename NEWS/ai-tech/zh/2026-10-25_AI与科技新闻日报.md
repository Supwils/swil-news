## 一、回报与资本开支

### 1. Apollo：科技业以外“财务回报为零”，词元支出高度集中（资本）
**摘要：** TechCrunch 10月25日报道，Apollo Global Management 首席经济学家 Torsten Slok 在10月24日的笔记中写道，尽管投资和宣传规模很大，人工智能给科技业以外的美国公司带来的财务回报为零。他比较的是所谓标普493，即标普500去掉 Alphabet、亚马逊、苹果、Meta、微软、英伟达和特斯拉。雅虎财经当天转述其图表：经通胀调整后，七巨头人均收入约78万美元，其余493家约52.5万美元；利润率分别接近30%和约10%。笔记称全要素生产率仍看不到人工智能带来的加速，主流公司开始把词元支出当成挤压利润率的成本；模型服务与推理支出的99.5%、新云支出的99%、与 OpenAI 和 Anthropic 相关支出的95%以上，来自支出最高的10%企业。

## 二、模型、漏洞与生物安全

### 3. 月之暗面发布 Kimi K3.1 Pro，权重拟于11月4日前公开（模型）
**摘要：** 月之暗面10月24日推出 Kimi K3.1 Pro，称其为迄今能力最强的3万亿级参数模型，上下文100万 token，完整权重计划在11月4日前发布。技术说明给出的 Terminal-Bench 4.0 为65.7%，高于其列出的 GPT-6 Astra（58.2%），接近 Claude Opus 5.5（66.4%）；高速版速度约为标准版的2至3倍。公司从中期训练和强化学习中移除网络攻防数据，自研 xdev-bench-hard 的 pass@3 从同一流程未移除时的90.5%降到81.0%，路透社称这一对比尚未独立核实。开放平台首页标价为标准版每百万 token 输入13元、输出68元，高速版为26元和136元。

**链接：**

- [Kimi API — Kimi K3.1 Pro](https://platform.kimi.com/docs/guide/kimi-k3-1-pro-quickstart)
- [Reuters — Moonshot curbs hacking ability in new Kimi model](https://www.investing.com/news/stock-market-news/moonshot-curbs-hacking-ability-in-new-kimi-model-as-fears-grow-over-aipowered-cyberattacks-4970639)

**简评：** 权重尚未放出，公司自己的测试已经写明：拿掉攻防数据压低了漏洞利用分数，通用编程能力仍会泛化到这类任务。

### 4. Unit 42：PHP2Shell 后渗透两小时触及密码哈希，CISA 同日口径不同（安全）
**摘要：** Palo Alto Networks Unit 42 在10月23日更新的威胁简报中写道，攻击者利用被称为 PHP2Shell 的两个 PHP 远程代码执行漏洞（CVE-2026-109618、CVE-2026-109619，CVSS 4.0 均为9.2），并使用智能体攻击平台做后渗透。简报称，在一起针对欧洲政府机构的案例中，初始利用后两小时内接触到密码哈希和多因素认证密钥，并建立 NTLM 中继隧道、尝试提升为域管理员；命令批次带有供模型读取的分隔符。Cortex Xpanse 当时统计到超过2260万个可能受影响的暴露实例。美国网络安全和基础设施安全局同日更新的警报则称，截至该警报发布时尚未观察到野外成功利用，并要求尽快升级到 PHP 8.5.12、8.4.27、8.3.36 或 8.2.35。

**链接：**

- [Unit 42 — PHP2Shell threat brief, updated October 23](https://unit42.paloaltonetworks.com/cve-2026-109618-cve-2026-109619/)
- [CISA — Critical vulnerabilities in PHP require immediate patching](https://www.cisa.gov/news-events/alerts/2026/10/21/critical-vulnerabilities-php-require-immediate-patching)

**简评：** 同一天的两份公开材料对是否已经打穿说法不一致，面向互联网的 PHP 可以先升到上述修复版本。
