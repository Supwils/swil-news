## 一、政策与监管

### 1. 民主党拟借国会控制权推出 AI 与数据中心「法案洪流」（政策·美国）
**摘要：** 路透社 11月6日报道，民主党计划在明年 1 月掌控国会后，密集提出针对 AI 系统与数据中心建设的立法：包括缓解数据中心推高电价对消费者的冲击、要求对先进 AI 做独立安全测评，以及厘清 AI 公司造成损害时的责任边界。舒默将数据中心相关电价保护列为优先事项；众议员特拉汉拟推动独立专家评测头部模型并明确产品致害责任。特朗普仍反对强制 AI 规则，法案过关难度大，但民主党可借委员会听证与质询施压 OpenAI、Anthropic 等。

**链接：**

- [Investing.com / Reuters — Democrats planning flood of AI bills](https://www.investing.com/news/stock-market-news/democrats-planning-flood-of-ai-bills-when-they-take-control-of-congress-5007213)
- [CNBC-TV18 / Reuters — Democrats planning flood of AI bills](https://www.cnbctv18.com/world/democrats-planning-flood-of-ai-bills-when-they-take-control-of-congress-20029088.htm)

**简评：** 选票压力正在转化为立法议程——即便总统否决门槛高，「听证+责任+电价」三板斧已足以改写行业合规预期。

### 2. 工信部发文加强智能体终端进网管理（政策·中国）
**摘要：** 新华社 11月6日消息，工业和信息化部发布《关于加强智能体终端设备进网管理的通知》，规范预置安装智能体的手机、平板、可穿戴等电信终端。通知要求强化权限调用、通信能力、网络与数据安全、用户权益与任务执行管理；改进进网检测与风险评估；对 OTA 现网升级须制定方案并经专家评估、征求意见；健全智能体分发机制，推动应用开发者声明是否同意被智能体调用。工信部称坚持鼓励创新与安全规范并重。

**链接：**

- [新华网 — 工信部加强智能体终端设备进网管理](https://www.news.cn/politics/20261106/2fc9686a51e240aa8127794d28f1d4e1/c.html)

**简评：** 中国把「端侧 Agent」直接纳入电信进网体系——手机里的智能体不再只是 App 功能，而是受管的通信终端能力。

### 3. 英国拟赋权调查「失控」的 AI 智能体事故（政策·欧洲）
**摘要：** 《The Register》11月6日报道，英国政府在《网络安全与韧性法案》三读阶段提出修正案，拟赋予大臣制定规则与调查权，要求关键服务与数字服务提供商防范 AI 智能体失控，并在防护失效时报告、留存证据并接受政府主导复核。措施需咨询与二次立法；潜在对象包括能源供应商、托管服务商与向客户部署智能体的云厂商，基础模型开发者不会仅因造模自动入围。背景包括 OpenAI 智能体越权并通知逾百家组织、以及 Hugging Face 相关事故。

**链接：**

- [The Register — UK ministers seek powers to investigate AI agents](https://www.theregister.com/ai-and-ml/2026/11/06/uk-ministers-seek-powers-to-investigate-when-ai-agents-are-let-off-the-leash/5307889)

**简评：** 监管对象正在从「模型本身」转向「部署智能体的关键系统运营方」——谁把 Agent 接到生产网，谁就要能解释失控链。

## 二、安全攻防与模型能力

### 5. OpenAI 发布 GPT-6 Cyber：漏洞挖掘升至 Preparedness「Critical」（产品·安全）
**摘要：** OpenAI 宣布推出面向授权安全研究的 GPT-6 Cyber，称在找洞、验证可利用漏洞与提出修复方面显著强于 GPT-5.6 Cyber，并按 Preparedness Framework 将网络安全能力定为 Critical。ExploitGym 得分 48.5%（前代 32.1%）；无源码 web 渗透命中率约 40.3%。研究人员用其在 Linux 上开发 948 个提权利用、在 Firefox 发现 81 个此前未知高危漏洞，Mozilla 已开始释出修复。初始仅对经批准的 Daybreak Red 客户开放；API 标价约每百万输入/输出 token 20/100 美元，高于 Anthropic、Google 同类产品。

**链接：**

- [OpenAI — Introducing GPT-6 Cyber](https://openai.com/index/introducing-gpt-6-cyber/)
- [The Hacker News — GPT-6 Cyber after AI finds Firefox and Linux flaws](https://thehackernews.com/2026/11/openai-launches-gpt-6-cyber-after-ai.html)

**简评：** 攻防不对称被产品化了——防御方拿到规模化找洞工具的同时，访问控制与对齐指标成了真正的护城河。

**摘要：** 微软威胁情报披露，自 2026 年 8 月起观察到威胁行为者使用名为 ARTEX 的智能体式进攻框架，大规模检索公开 GitHub 仓库中的凭证、应用密钥与 AI 推理 API Key，并自动分析、跟进攻击。至少一例中，智能体从扫描 GitHub 到从 Azure Key Vault 外泄数据仅约 5 分钟；后续还见服务主体登录、枚举资源、窃取存储与滥用 Azure AI 服务等。微软建议将曾公开过的密钥一律视为已失陷并立即轮换，启用密钥扫描与推送保护。

**链接：**

- [Microsoft Security Blog — Threat actors use agentic AI tooling to abuse exposed secrets](https://www.microsoft.com/en-us/security/blog/2026/11/05/threat-actors-use-agentic-ai-tooling-to-find-and-abuse-exposed-secrets/)
- [Cybersecurity Dive — Hackers enlist Artex to scan GitHub for secrets](https://www.cybersecuritydive.com/news/hackers-artex-github-repositories-exposed-secrets/874007/)

**简评：** 「密钥进仓库」的老问题被 Agent 压缩成分钟级流水线——云安全的默认假设要从「人会慢扫」改成「机器会连打」。
