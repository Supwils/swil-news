### 5. Anthropic：Claude 智能体自主发现类 CRISPR 重复阵列酶系统 ART（科研）
**摘要：** Anthropic 9 月 23 日发文并持续发酵：春成立生命科学组与湾区 BSL-1/2 实验室后，约 950 个 Claude 智能体用约 2.1 亿 token、21 小时在序列库中筛逆转录酶，发现噬菌体中「逆转录酶 + 伴生蛋白 + 串联 DNA 重复阵列」的 ART 系统；阵列可转录为大量短 RNA，功能与可编程性尚未证实。湿实验由人类完成；预印本指出该 RT 本身曾被报告，新颖点在阵列与伴生基因。Feng Zhang 称「值得继续探究」。独立评论指出十次重跑未能复现该发现，强调过程非确定性。

### 6. Nvidia 论文 SoL-Pi：自动优化编码 Agent 控制层，Token 可降近半（研究）
**摘要：** THE DECODER 9 月 26 日报道 Nvidia 新论文：系统 SoL-Pi 用研究智能体分析另一 Agent 轨迹，在 535 个可执行环境中探索 152 条方向，自动改写 harness（状态呈现、工具调用、上下文压缩等），与模型本身无关。在隔离的 EdgeBench 上，四机制全开变体 Token 约减 49%、得分约达原 Pi harness 的 93.7%；相对原生 Codex / Claude Code harness 估算可省约 8.75–13.50 美元/小时。作者强调与搜索隔离的评测以防过拟合，跨基准表现更混杂。

**链接：**

- [THE DECODER — Nvidia's SoL-Pi system cuts coding agent token usage nearly in half](https://the-decoder.com/nvidias-sol-pi-system-cuts-coding-agent-token-usage-nearly-in-half-by-optimizing-the-harness/)

**简评：** Agent 成本战争已从换更便宜模型，推进到「自动改写控制平面」——harness 本身成为可优化资产。
