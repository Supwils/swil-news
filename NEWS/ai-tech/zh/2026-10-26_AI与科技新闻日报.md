**摘要：** SpaceX 在10月26日提交的 8-K 中披露，公司已于10月24日与 Apollo 管理的实体签署有约束力的承诺函，拟订立主融资租赁：出租方购入 GPU 机柜及相关设备，再租给 SpaceX，用于公司选定的数据中心。各批次租期约为交付起算的五年至五年三个月，租金按季预付，一般为该批融资成本的二十分之一，另加按未偿余额计算的固定利率；各批次本金合计预计约400亿美元。交易仍取决于约定的交割条件，预计2026年年底前完成，租约预计于2027年上半年 GPU 交付后起租。公司同日声明称，这笔租赁将提供下一代英伟达 Vera Rubin 芯片，并称之为已承诺的最大一笔 GPU 融资；首席财务官 Bret Johnsen 说，超智能基础设施投资的回收期不到一年，资金将用于企业与消费者侧的 Grok 以及云服务。高盛担任唯一结构性安排行，贝莱德、高盛资产管理和 KKR 顾问的资本账户作出锚定承诺。

### 8. OpenAI 发布 GPT-6.1 Terra，标准 API 输入价降至每百万 token 1 美元（产品）
**摘要：** OpenAI 10月26日推出 GPT-6.1 Terra，面向屏幕理解、电脑操作和文字写作，已向 ChatGPT Work 与 Codex 中的 Plus、Pro、Enterprise 和 Edu 用户开放，API 模型名为 gpt-6.1-terra。官方文档标价为标准档每百万 token 输入1美元、缓存输入0.05美元、输出5美元；公司称标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低50%。在其 Agents' Last Exam 上，中等推理强度的 Terra 比 GPT-5.6 Terra 高15个百分点，成本约为三分之一，并称按每 token 价格计与 GPT-6 Astra 持平、只及其十分之一，完成任务的速度平均比 Astra 和 GPT-6.1 Sol 快三倍以上。内部易错提示测试中，低推理强度的错误率从 GPT-5.6 Terra 的53.6%降到16.7%；最高强度下降18个百分点至4.3%。Terminal-Bench 4.0 在最高推理强度下为50.3%，高于公司列出的 GPT-5.6 Terra 已公布成绩21.5%。公司称该模型在其准备框架下达到网络安全的 Critical 阈值。上下文窗口为105万 token，知识截止日期为2026年6月1日。
