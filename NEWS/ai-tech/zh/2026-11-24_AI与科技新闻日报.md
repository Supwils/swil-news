## 二、大模型科研与产品

### 4. OpenAI：GPT-6 展现内禀蛋白质设计能力，实验室验证部分结合活性（研究）
**摘要：** OpenAI 11 月 24 日发文称，GPT-6 系列可仅凭推理与代码设计新蛋白结构与氨基酸序列，无需调用专用生物模型生成设计本身；内部研究模型在多项蛋白设计任务上达到或超过专用模型。与 Onava 合作的实验室测试中，基于 GPT-6.2 设计的 322 个 minibinder 针对 5 个靶点，有 35 个（10.9%）呈现结合阳性。公司同时强调仍依赖 Boltz-2、ESMFold2 等专用模型筛选候选，尚未证明可零样本端到端生成全新结合蛋白，结构预测等任务仍明显落后于专用系统。

**链接：**

- [OpenAI — GPT-6 models demonstrate intrinsic protein-design capabilities](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)

**简评：** 通用模型侵入湿实验管线，但「能画骨架」不等于「能成药」——真正分水岭仍是特异性、稳定性与安全评估闭环。

### 7. Google Gemini API 上线原生文件切片：按页/单元格/片段计费（产品 / 开发者）
**摘要：** Google 宣布在 Gemini API（含 AI Studio 与 Gemini 平台）上线原生文件切片，并支持直接上传 Microsoft Office 与 OpenDocument 格式。开发者可服务端指定 PDF/演示文稿页码、电子表格区域、音视频时间段与内容层（如文本/图像/公式/帧），仅对实际检视部分计费；一次上传的 Files API URI 可跨轮次复用，Agent 也可在 function response 内指定切片。功能覆盖全部 Gemini 4 模型，原有文件大小与页数限制仍适用。

**链接：**

- [Google Blog — Introducing file slicing controls in the Gemini API](https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/)

**简评：** Agent 时代的隐性成本是「整文件硬塞」——切片把多模态输入从本地转码沙箱拉回云端原生能力，比堆上下文窗口更务实。
