### 4. Meta 发布最轻量 Muse Ember：主打智能体高频执行与性价比（产品）
**摘要：** Meta Superintelligence Lab 11月9日发布 Muse Ember，自称目前最小、最省成本的 Muse 系列模型，面向工具调用、编码子任务、路由、抽取与长文档解析等智能体高频重复工作；输入约 0.10 美元/百万 token、输出约 0.50 美元/百万 token，上下文约 100 万 token，即日起在 Meta Model API 与 Muse Code 以 `muse-ember-1.0` 提供。官方称在 Artificial Analysis 综合指标上「每美元智能」优于 Claude Haiku 5.5 与 GPT-6 Luna，并定位与更大模型 Muse Wonder 搭配——「Wonder 规划，Ember 扛量」；支持文本、图像与音频等多模态输入。

### 6. OpenAI 上线 Control Room：可在约 35 秒内叫停研究侧模型负载（安全）
**摘要：** OpenAI 11月9日介绍已在研究基础设施部署 Control Room：集中追踪研究推理负载（含训练/评测中的智能体采样、数据处理等），并与未对齐监控联动；自决定干预起最长约 35 秒内可停止继续产出（延迟来自授权缓存层，公司称正努力压至接近零）。系统设计为「失效即关闭」（fail-closed）：若 Control Room 自身故障或被禁用，推理请求将被拒绝直至恢复；前沿模型研究负载已覆盖，其余研究负载将在数日内完成 rollout。对外服务栈则称本就更集中、具备快速下线能力。
