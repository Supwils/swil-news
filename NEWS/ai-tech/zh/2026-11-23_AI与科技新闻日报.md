## 三、大模型、Agent 与安全产品

### 7. OpenAI 与思科开源 Shirudo：用 eBPF 给运行中的 Linux 打「临时盾」（安全 / 产品）
**摘要：** OpenAI 与思科 11 月 23 日联合发布开源运行时 Shirudo（日语「盾」），基于 eBPF 在无需重启的情况下为运行中的 Linux 系统部署可验证的临时防护（shield）。演示中，Codex 生成的 shield 在不停机的 Elasticsearch 上拦截了 Java4Shell 利用尝试；项目强调 live protection、面向 Agent 的可编程防御、密码学签名部署与 TPM 硬件背书的加载记录，并邀请业界共同开发。

**链接：**

- [OpenAI — OpenAI and Cisco introduce Shirudo](https://openai.com/index/introducing-shirudo/)

**简评：** 把「补丁窗口」变成可编程战场——Agent 写盾、人审批准，安全运维正从工单制迈向机速闭环。

### 8. Anthropic 推出 Claude Ship：Agent 可按策略自动审批代码变更（产品）
**摘要：** Anthropic 11 月 23 日宣布推出 Claude Ship（测试版）：在已正式可用的 Code Review 之外，新增 PR Steward（处理 CI 失败、合并冲突与评审反馈）与 Claude Approvals（按仓库内自然语言策略自动批准常规变更）。面向 Claude Team/Enterprise 与 GitHub 仓库开放；公司建议先以 observe-only 模式运行审批 Agent，并可限制仓库范围与月度支出。人类仍可配置审查深度与必须升级人工的变更类型。

**链接：**

- [TechCrunch — Anthropic launches Claude Ship, letting AI agents review, fix, and approve code changes](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)

**简评：** 写代码已不够，下一战场是「谁有权点 Merge」——把审批权交给策略文件，等于把工程治理本身产品化。

### 10. DeepMind：Gemini Agent 团队用形式化验证改进量子算法并开源 Lean 库（研究）
**摘要：** Google DeepMind 11 月 23 日发文称，用 Gemini 4 Agent 团队改进已知量子算法，并用 Lean 形式化定理证明器验证结果；在惯性约束聚变相关电路上将综合计算成本降低约 11.8 倍、纠错量子比特需求自 5650 降至 4338，药物代谢分子与细胞色素 P450 等模拟亦分别取得约 8 倍与 2.5 倍成本改善，并对 Grover 实现与 arcsin 例程给出加速。公司同步在 GitHub 开源 Lean 库、问题规格与已验证解法。

**链接：**

- [Google DeepMind — Finding faster quantum algorithms with agents and formal verification](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)

**简评：** Agent + 形式化验证把「AI 发现算法」从论文演示推进到可机器验收的电路优化——量子近期可用性仍远，但研发流水线已变。
