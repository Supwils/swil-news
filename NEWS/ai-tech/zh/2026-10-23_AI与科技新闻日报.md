## 一、政策与监管

### 1. 美国证监会：2027财年检查把“超级智能”列入重点（监管）
**摘要：** 美国证券交易委员会10月23日发布2027财年检查优先事项（新闻稿2026-109）。检查覆盖超过3.4万家注册机构，重点包括投顾信义义务与利益冲突、面向零售投资者的复杂和低流动性产品、私募基金与私人信贷、经纪商财务责任和反洗钱、运营韧性与网络安全，以及可能影响市场运行、合规、防欺诈和投资者保护的新兴技术；新闻稿把“超级智能”写进这一项，并单独点出国债清算改革和证券代币化。InvestmentNews 称，检查部门将查看机构如何应对超级智能生成的钓鱼信息，以及用于社会工程的深度伪造语音和视频，也会看机构在欺诈检测、后台、反洗钱、最佳利益监管和交易中如何监控自身对这项技术的使用；这些优先事项不是完整清单。

**链接：**

- [SEC — SEC Announces Fiscal Year 2027 Examination Priorities](https://www.sec.gov/newsroom/press-releases/2026-109-sec-announces-fiscal-year-2027-examination-priorities)
- [InvestmentNews — SEC’s 2027 exam priorities put RIA conflicts and cyber risks in focus](https://www.investmentnews.com/regulation-legal-compliance/secs-2027-exam-priorities-put-ria-conflicts-and-cyber-risks-in-focus/268722)

**简评：** 新闻稿换成了“超级智能”这个词，检查要看的仍是机构自己的使用方式和对外防护，不是一道新的模型许可。

### 2. 日本总务省：选举平台指针草案要求探测人工智能图像（政策）
**摘要：** 总务省10月23日就减轻选举不公正影响的措施指针草案，以及信息流通平台法施行规则修正案公开征求意见，提交期为10月24日至11月24日，指针拟随2027年3月1日生效的改正法施行。时事通信报道，对象包括谷歌、X 和 LINE Yahoo 在内的13家大型社交平台；建议措施包括停止损害选举公正的帖子变现，以及探测人工智能生成的图像和视频并向用户显示警告，具体做法交给企业，不设罚则。改正公职选举法已规定，正式竞选期间在网上散发由人工智能制作或改动的图像、视频必须标明，按社会观念属于轻微改动、或不致被误认为实拍的除外。总务大臣藤井比早之说，将推动业者采取有效措施，并争取让指针赶上明年4月的统一地方选举，最早可能在年内定稿。

**链接：**

- [总务省 — 选举公正措施指针案等意见征集](https://www.soumu.go.jp/menu_news/s-news/01ryutsu02_02000497.html)
- [时事通信 — 选举虚假信息、停止变现，人工智能探测等社交平台指针案](https://www.jiji.com/jc/article?g=pol&k=2026102300419)

**简评：** 标明义务已经写进选举法，这份指针追加的是平台侧的探测、警告和停变现，而且没有罚则。

**摘要：** OpenAI 10月23日宣布，已与波兰国家研究机构 NASK 签署协议，探讨在人工智能安全、安保和技术研究上合作。NASK 的人工智能安全研究中心将作为波兰人工智能安全研究所，与 OpenAI 一起评估能力更强的系统、识别弱点并加强防护。协议延续既有的网络防御合作：今年7月，设于 NASK 的 CERT Polska 经 Daybreak 使用 OpenAI 的网络能力模型，帮助发现 MikroTik RouterOS 中的6个漏洞，其中包括可组合起来、在未经认证的情况下控制受影响设备的缺陷；厂商已发布修复，CERT Polska 确认这些修复挡住了它观察到的攻击。

**链接：**

## 二、漏洞与安全响应

### 4. PHP2Shell：尝试扩大，厂商仍未确认成功入侵（安全）
**摘要：** SecurityWeek 10月23日报道，PHP 于10月21日发布补丁两天后，已有攻击者尝试借助 PHP2Shell（CVE-2026-109618 与 CVE-2026-109619，CVSS v4.0 各为9.2）传播 Mirai 僵尸网络变种；一家安全公司还做出可绕过地址随机化的利用，但截至当天没有确认的野外成功入侵。亚马逊威胁情报称，10月17日其蜜罐已记录到一次利用尝试，比公开披露早四天，补丁发布后针对传感器的尝试明显变广，这些尝试能否在真实系统上成功仍不清楚。Sophos 在10月23日的更新中更正前一日“已有成功利用”的说法，称客户遥测目前是扫描和少量失败尝试，没有成功失陷的证据；同日它还写道，PHP 另发布了一项需异常配置与应用代码组合才会触发的远程代码执行通报（CVE-2026-115560），并称针对 CVE-2026-109619 的缓解也覆盖该问题。对应补丁版本为 8.5.12、8.4.27、8.3.36 和 8.2.35。

**链接：**

- [SecurityWeek — Mirai botnet operators join PHP2Shell attacks](https://www.securityweek.com/mirai-botnet-operators-join-php2shell-attacks-as-aslr-bypass-exploits-emerge/)
- [Sophos — Proof-of-concept exploit released for PHP vulnerabilities](https://www.sophos.com/en-us/blog/proof-of-concept-exploit-released-for-php-vulnerabilities-109618-109619)

**简评：** 周五新增的是尝试范围和一条更正：这些厂商写出了大规模尝试，没有写出一份已确认的失陷名单。

### 6. x402：25处漏洞中的3处严重问题据称已在8月修复（安全）
**摘要：** The Hacker News 10月23日报道，安全公司 V12 在智能体用于为 API 付款的 x402 代码中发现25处漏洞，其中3处被标为严重。x402 由 Coinbase 发起，现由 Linux 基金会旗下的 x402 Foundation 维护。V12 称，8月18日的版本之前，默认客户端没有支出上限，恶意 API 可能让自动签名的智能体授权花掉所支持代币的全部余额；另外两处严重问题分别涉及把未实际转账的 Solana 交易当成有效付款，以及签署指向其他网站的登录消息。基金会已在8月18日的版本中修复这三处问题，但没有发布安全公告，更新日志也未把修复标成安全修复；截至10月23日，The Hacker News 检查到修复前的最后一批 TypeScript 与 Python 版本在 npm audit 和 PyPI 上没有对应警告，V12 与基金会均未公开报告已有人利用这些缺陷发起攻击。

**链接：**

- [The Hacker News — Critical x402 SDK flaw could let malicious APIs drain AI agents’ token balances](https://thehackernews.com/2026/10/critical-x402-sdk-flaw-could-let.html)
- [V12 — 25 vulnerabilities in the x402 protocol](https://v12.sh/blog/x402)

**简评：** 严重问题的修复日期写的是8月18日，10月23日新公布的是没有安全公告，常规审计工具不会提醒升级。
